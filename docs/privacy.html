1. Responsável pelo Tratamento

O responsável pelo tratamento dos teus dados é Olavo Ferreira, contactável através de ferreiraolavo21@gmail.com.

2. Dados que Recolhemos

Categoria Dados Finalidade
Conta Email, password (hash) Autenticação
Perfil Nome, tipo de investidor, horizonte temporal, metas orçamentais Personalização da experiência

3. Base Legal

O tratamento dos teus dados assenta nas seguintes bases legais (Artigo 6.º do RGPD):

  • Execução do contrato — para prestar o serviço que solicitaste.
  • Consentimento — para funcionalidades opcionais (notificações, integrações).
  • Interesses legítimos — para melhorar o serviço e detetar fraudes.

4. Onde são Armazenados os Dados

Os teus dados são armazenados na plataforma Supabase (PostgreSQL), com servidores na União Europeia (região eu-west). A Supabase está em conformidade com o RGPD e assina Cláusulas Contratuais-Tipo (SCCs).

As passwords nunca são armazenadas em texto claro — são processadas via bcrypt pelo serviço de autenticação da Supabase.

5. Partilha com Terceiros

Os teus dados não são vendidos nem partilhados com terceiros para fins comerciais. São partilhados apenas com subcontratantes estritamente necessários à prestação do serviço:

  • Supabase Inc. — armazenamento e autenticação
  • Expo (React Native) — distribuição da aplicação móvel

6. Os Teus Direitos (RGPD)

Tens os seguintes direitos relativamente aos teus dados pessoais:

  • Acesso — consultar os dados que guardamos sobre ti.
  • Retificação — corrigir dados inexatos.
  • Eliminação — solicitar a remoção da conta e de todos os dados associados.
  • Portabilidade — exportar os teus dados em formato legível por máquina.
  • Oposição — opor-te ao tratamento baseado em interesses legítimos.

Para exerceres qualquer destes direitos, contacta-nos em ferreiraolavo21@gmail.com. Responderemos no prazo máximo de 30 dias.

Tens ainda o direito de apresentar reclamação à CNPD (Comissão Nacional de Proteção de Dados).

7. Retenção de Dados

Os dados são conservados enquanto a conta estiver ativa. Após pedido de eliminação, os dados são removidos no prazo de 30 dias, exceto os que sejam exigidos por obrigação legal.

8. Segurança

Adotamos medidas técnicas e organizativas adequadas para proteger os teus dados, incluindo: transmissão via HTTPS/TLS, bases de dados com Row Level Security (RLS), e chaves de API cifradas com AES-256-GCM.

9. Alterações à Política

Esta Política pode ser atualizada periodicamente. Alterações significativas serão comunicadas através da aplicação. A data de "última atualização" no topo deste documento reflete sempre a versão mais recente.
