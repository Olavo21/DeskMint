# v1.2.0

## Novidades
- **Ligações a brokers**: Trading212 API key encriptada via AES-256-GCM Edge Function
- **Calculadoras** (Ferramentas): Triângulo Financeiro, Motor FIRE, Simulador FIRE, Otimizador de Dívida, Simulador Mais-Valias PT 28%
- Multi-moeda: `fmt()` / `useFmt()` lê moeda de `preferencesStore`
- i18n: sistema de chaves aninhadas (`t('investments.title')`, `t('common.save')`)
- Ecrã Assistente redesenhado: 6 cards analíticos (sem chat)
- Hermes JS engine activado explicitamente em `app.json`
- Zustand atomic selectors para prevenir re-renders desnecessários

## Correções
- `AsyncStorage` lazy-loaded via `require()` em try/catch em `i18n.ts`, `currencies.ts`, `definicoes.tsx`
